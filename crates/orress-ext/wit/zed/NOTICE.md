# Vendored Zed extension API (WIT)

These `.wit` files are the **public** Zed extension API (`zed_extension_api`, version
`since_v0.6.0`), copyright Zed Industries, Inc., licensed **Apache-2.0**. They are vendored
verbatim so ORRESS can implement a **clean-room host** for the same world — no Zed engine code is
used. ORRESS itself is MIT OR Apache-2.0, which the Apache-2.0 WIT is compatible with.

Source: the `zed_extension_api` crate, `wit/since_v0.6.0/`.
